| 1 | HISS-F1-05 Exception and operational override register | Any departure from a HISS control made to keep guest service running, such as a shared front desk logon during an outage or a vendor session opened without approval, shall be entered in an exception register with the reason, approving manager, compensating measure and expiry. The register shall be reviewed monthly. | | | |
| 2 | HISS-F3-02 Leaver removal within the shift | Access for any worker who leaves, ends a seasonal contract or is withdrawn by an agency shall be disabled before the end of the shift in which the exit is recorded. Badges, key cards and devices shall be returned or disabled the same day. | | | |
| 3 | HISS-F4-01 Individual logons on shared terminals | Every person using a shared terminal or the PMS shall log on with an individual account. Shared terminals shall support fast user switching or a badge tap so that individual logon does not slow check in. | | | |
| 4 | HISS-F5-02 Patch windows that fit round the clock operation | Security patches shall be applied within set windows by severity, with critical vulnerabilities fixed within 30 days at most and sooner on internet facing or Tier 1 systems, using agreed low occupancy windows, a tested rollback and a manual fallback briefing for the front desk. | | | |
| 5 | HISS-F6-05 Manual front desk fallback | Each property shall keep a tested manual fallback for check in, check out, key issue and charge posting during a PMS or network outage, with paper forms stored securely, a limit on what card data may be written down and a procedure to re enter and then destroy the records after recovery. | | | |
| 6 | HISS-H05-03 Default credential removal on engineering devices | Default and shared passwords on controllers, panels, gateways and engineering software shall be changed at commissioning and stored in a vault. Devices that cannot change them shall be listed as exceptions with compensating isolation. | | | |
| 7 | HISS-H07-03 Time windowed vendor access with approval | Vendor accounts shall stay disabled by default and be enabled for a set window only after approval by the system owner at the property, with out of hours emergencies approved by the duty manager and entered in the exception register. | | | |
| 8 | HISS-H08-02 Identity document capture and masking | Passport and identity document images shall be captured only where law or a stated purpose requires, stored in one controlled location linked to the stay, masked on screens and printouts where the full number is not needed and encrypted at rest. | | | |
